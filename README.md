# Default community health files

Shared issue and pull request templates for my repositories. GitHub applies them to any repo of mine that does not have its own `.github` folder.

- `pull_request_template.md`: what changed, why, data and method, results, and a reproducibility and data-safety checklist
- `ISSUE_TEMPLATE/analysis-task.md`: a new analysis, model or feature
- `ISSUE_TEMPLATE/bug-or-data-issue.md`: something wrong with code, data or results
